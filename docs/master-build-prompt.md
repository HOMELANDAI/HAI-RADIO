# Master Build Prompt

Design a fully customized web-based mainframe system titled **HAI RADIO** for HomelandAI.

HAI RADIO is the central nervous system of the HomelandAI audio and venue ecosystem: a premium internet radio interface, venue signal map, NPC host universe, song submission court, Twitch/Maestro interaction layer, Playlist Pulse gateway, and custom branded Radio.co-powered listening experience.

Use Radio.co as the broadcast engine while creating a completely custom HomelandAI front-end powered by HAI branding, Supabase data architecture, NPC personalities, Playlist Pulse integration, venue intelligence, and interactive overlays.

Important distinction: **The HAI Frequency is a separate but connected HomelandAI weekly podcast property.** It should not be treated as a core HAI Radio segment or built-in radio block. It should appear inside the HAI Radio interface only as a gateway, tab, button, or pathway that allows users to access The HAI Frequency.

## Visual style

Create a retro-futuristic music command center using dark cinematic backgrounds, neon cyan HAI glow, electric blue grid lines, chrome borders, glassmorphism panels, violet and magenta accents, animated waveform meters, holographic venue nodes, rear-POV NPC DJ visual language, glowing venue-map architecture, neon block-card structure, and luxury AI dashboard styling.

## Pulse button

Add a small but visible glowing Pulse Button near the Listen Live player, HAI Stream Beacon, or lower-right action dock. The button should glow and pulse rhythmically. When pressed, it opens a modal titled **Playlist Pulse: Winning Playlist** showing the winning Playlist Pulse playlist in numerical order.

## High Frequency gateway

Add a pathway to The HAI Frequency as a separate weekly podcast property connected to HomelandAI. Do not place it in the block rotation. Do not present it as a HAI Radio segment.

## Final brand statement

HAI Radio is not just a music station. It is the voice, rhythm, commentary layer, game gateway, and central nervous system of the HomelandAI audio and venue universe.
