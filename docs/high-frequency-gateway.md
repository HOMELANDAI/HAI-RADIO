# High Frequency Gateway

## Key distinction

The HAI Frequency is a separate but connected HomelandAI weekly podcast property. It is not a HAI Radio music block and not a built-in radio segment.

## Interface treatment

Inside HAI Radio, The HAI Frequency should appear only as a gateway, tab, button, card, or connected media node.

Do not:

- include it in music block rotation
- treat it as a radio block
- label it as a HAI Radio segment
- confuse it with Song Diary

## Gateway content

The gateway should show:

- podcast logo/show identity
- latest episode title
- short description
- release date
- Open High Frequency button
- Watch Latest Episode button
- Listen to Episode button
- View Archive button

## Suggested copy

The HAI Frequency is a weekly HomelandAI podcast featuring specialized NPCs and voices discussing HomelandAI projects, music culture, AI creativity, technology, philosophy, venue developments, and community moments.

## Design principle

Connected to HAI Radio, but not contained by HAI Radio.
