# Playlist Pulse Gateway

## Definition

Playlist Pulse is a HomelandAI-created and curated music game connected to HAI Radio through a glowing Pulse Button and gateway node.

## Role inside HAI Radio

Playlist Pulse is a game pathway, not a normal music block. It allows passive listeners to become active participants in music sequencing, voting, and playlist competition.

## Pulse Button behavior

The Pulse Button should:

- glow rhythmically
- pulse like a heartbeat or audio meter
- appear near Listen Live, the Stream Beacon, or mobile bottom navigation
- open a winning playlist modal when clicked
- intensify when a new winning playlist is available

## Winning playlist modal

Title: Playlist Pulse: Winning Playlist

Fields:

- playlist title
- playlist theme
- ordered songs
- winning user/team
- curator note
- NPC commentary
- vote totals
- action buttons

## Modal buttons

- View Full Playlist
- Enter Playlist Pulse
- Listen on HAI Radio
- Share Winning Playlist
- Close
